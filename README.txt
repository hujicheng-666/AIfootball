AIfootball 使用说明
==================

AIfootball 是一个 Windows 桌面端点球轨迹分析平台。它通过双摄像头视频完成足球检测、三维轨迹重建与弹道拟合，并将结果导出到 Unity 查看器进行点球回放和门将仿真。

1. 系统要求
-----------

- Windows 10/11 64 位
- 建议使用 NVIDIA GPU；没有独立显卡时可使用 CPU 模式，但处理速度较慢
- 双摄像头采集时，需要两台可被 Windows 识别的摄像头
- 首次配置推理环境与模型时需要联网

2. 安装与启动
-----------

若收到安装包，请运行 AIfootball-Setup-2.0.0-x64.exe，按向导完成安装，然后从开始菜单或桌面快捷方式启动 AIfootball。

首次启动时：

1) 在“仪表盘”确认系统环境状态。
2) 若显示“需要设置”，点击“一键安装环境”。
3) 等待 Python、推理依赖和模型配置完成；完成后状态显示“环境就绪”。

首次环境安装可能耗时较长，取决于网络、GPU 与模型下载速度。安装过程中不要关闭程序。

3. 推荐工作流程
---------------

相机标定（首次或相机位置改变后）
  -> 录制 / 准备左右双目视频
  -> 离线处理或在线录制
  -> 3D 重建 -> 弹道拟合 -> 导出 Unity CSV
  -> 查看结果 / 启动 Unity 回放

4. 相机标定
-----------

打开左侧导航中的“相机标定”。标定包含两部分：

1) 内参标定：分别使用左右相机拍摄的棋盘格素材，计算焦距、主点与畸变参数。
2) 外参标定：在两台相机共同观察的场景中建立相对位姿关系。

当摄像头位置、焦距、分辨率或安装角度发生变化时，应重新标定。完成后，标定文件保存到 calib 目录，后续重建会自动使用它们。

5. 处理双目视频
---------------

打开“处理流水线”。可使用离线处理或在线录制。

离线处理：

1) 将一个样本放入 samples\<样本名称>\。
2) 样本目录中应正好包含左右两个 .mp4 视频文件。
3) 在应用中选择样本；需要时可勾选跳过某个步骤。
4) 点击“开始离线处理”。

程序会依次完成足球检测、双目三角化重建、弹道拟合以及 Unity 轨迹 CSV 导出。

在线录制（支持两种采集方式，界面里可切换）：

方式一：USB/有线相机（相机直连电脑）
1) 选择左右摄像头设备（默认 0、1）。
2) 点击"检测摄像头"可查看当前可用的本地相机。
3) 输入本次采集的样本名称，开始录制和处理。

方式二：手机/网络相机（两台手机 + 路由器，替代购买相机）
原理：两台手机通过路由器 WiFi 组成局域网，把摄像头画面实时推流到电脑，
      电脑作为接收端读取两路视频流完成与有线相机相同的录制与重建。
步骤：
1) 两台手机安装推流 App（Android 推荐 "IP Webcam" 或 "RTSP Camera"）。
2) 手机连接路由器 WiFi 并开启推流，记下手机显示的视频流地址
   （形如 http://192.168.1.101:8080/video 或 rtsp://192.168.1.101:8554/...）。
3) 在"在线录制"里切换到"手机/网络相机"，把两个地址分别填入左/右路。
4) 点击"测试连接"确认画面可达，再开始录制。
注意：
- 两台手机与电脑必须连接同一路由器。
- 推流期间手机要保持常亮、关闭省电/锁屏。
- 分辨率帧率受 WiFi 带宽限制，建议先测 720p@30fps。
- 相机标定同样使用这两台手机拍摄棋盘格素材（内参）与共同视野（外参）。

边录制边分析（可选，勾选"⚡ 边录制边分析"开启）：
- 录制的同时对左右画面实时检测足球，预览窗口叠加检测框、置信度、
  实时 3D 轨迹点和球速（需已完成相机标定）。
- 停止录制后，直接使用录制过程中已累积的检测结果生成 3D 重建 +
  弹道拟合 + Unity 导出，不需要重跑整段视频检测（立即出结果）。
- 录制文件仍会保存（VID_left.mp4 / VID_right.mp4），可随时用离线流程重跑。
- 若实时检测点不足（如球没被检测到），会自动回退到离线重跑检测。
- 提示：实时性取决于推理速度。GPU 建议每帧分析；CPU 较慢时可使用
  命令行参数 --analyze-every 2/3 抽帧分析（界面暂未开放，独立版可用）。

无论哪种方式，都建议先用短视频测试同步、视野和标定效果，再开始正式采集。

6. 查看结果
-----------

常用目录：

- output\trajectory_3d\<样本>：3D 重建点、轨迹图和摘要。
- output\trajectory_ballistic\<样本>：弹道拟合曲线、参数和摘要。
- data\<样本>_trajectory.csv：提供给 Unity 回放的轨迹 CSV。
- data\goalkeepers：Unity 门将能力预设。

选择“启动 Unity 查看器”后，程序会把当前样本的轨迹传给 Unity。Unity 负责回放、切换视角、选择门将和记录仿真结果；相机标定、3D 重建与弹道拟合仍由主程序完成。

7. 常见问题
-----------

环境一直显示“需要设置”
确认网络可用，然后点击“一键安装环境”。若安装失败，请查看仪表盘底部运行日志，并检查杀毒软件、代理或防火墙是否拦截了 Python 和模型下载。

样本显示未重建或未拟合
这是由工作目录中的实际文件决定的：

- 存在 output\trajectory_3d\<样本>：显示已重建。
- 存在 output\trajectory_ballistic\<样本>：显示已拟合。
- 存在 data\<样本>_trajectory.csv：可供 Unity 回放。

Unity 查看器黑屏或闪退
请使用与当前主程序同一安装包中的 Unity Viewer，不要单独复制旧版 Viewer 到主程序目录。若仍出现问题，请提供 Unity 日志：

C:\Users\<用户名>\AppData\LocalLow\DefaultCompany\Myproject\Player.log

摄像头画面或重建质量不稳定
检查左右视频是否同步、球是否在两台相机中都清晰可见，并确认标定文件与当前摄像头位置、分辨率一致。

8. 开发运行与打包
-----------------

开发运行：

  cd D:\AIfootball\src
  dotnet run --project AIfootball.App

构建发布目录：

  D:\AIfootball\scripts\build_release.bat

使用 Inno Setup 打包时，打开 D:\AIfootball\installer\AIfootball.iss 并按 Ctrl + F9。
最终安装包输出到 dist\installer。
